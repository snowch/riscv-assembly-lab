What is this program asking xv6 to do?

The write system call sends bytes to the console. Registers a0, a1 and a2 hold its arguments: output file, message address and byte count. a7 selects the system call. ecall enters the operating system.

The program then calls exit to finish. These system call numbers belong to xv6: write = 16, exit = 2. Linux and teaching simulators can use different numbers.

li loads a number; la loads an address. They are assembler pseudo-instructions which GNU as translates into RISC-V machine instructions.

How the browser builds and runs it

GNU as assembles your source and GNU ld links a real ELF64 executable. It is installed as workbench in a fresh xv6 filesystem. The WebAssembly RISC-V CPU boots xv6 and runs that executable.

This first prototype runs one assembly file targeting RV64GC / LP64D, with an entry named _start. It has console output and a Stop button. Source is limited to 64 KiB, executables to 256 KiB and execution to 30 seconds. Console input and stepping are future work.

No compilation server or account is needed. Your draft saves in this browser when storage is available. Each run starts a disposable machine; guest filesystem changes are discarded.
