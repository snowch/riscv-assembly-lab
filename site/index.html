Learn RISC-V assembly by running it.

Start with three instructions. Build towards functions, C, complete xv6 programs and a trip computer that boots on bare metal.

Before you start

You should know basic C, including variables, if statements, loops, functions and arrays. You can read small binary numbers using place values. No assembly, hexadecimal, two’s complement or pointers are assumed. Bit Lab offers an optional binary refresher.

Optional guide: Using the workbench.

Registers hold bits. Instructions decide what they mean.

Predict a result, run or step the code, inspect registers and bytes, then change the example. Each optional exercise checks your code on fresh inputs. Tools → Program shows the supplied entry and reporting code.

The target is 64-bit RISC-V with the RV64GC instruction set and the standard integer calling convention. Programs run as real xv6 user processes. RISC-V has no Arm condition flags; the arithmetic and branch lessons teach its own mechanisms.

An assembler turns assembly text into machine-code bytes. A linker joins those pieces and resolves their addresses to make an executable file. The GNU assembler and linker do that locally here. The C lessons add the pinned TinyCC compiler. Source drafts and completion marks stay in this browser; guest files are disposable. Sources and runtime details.
