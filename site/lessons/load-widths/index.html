Module 6 · Memory and transfer widths

Choose how a narrow load fills a register

Compare sign extension and zero extension of the same memory bits.

Loading lesson…

These observations belong to the source captured at the start of this run. Build again to use your edits.

A signed sensor byte and an unsigned fuel byte can contain the same eight bits but represent different numbers. A 64-bit register needs more bits than either byte supplies. The load instruction decides how to fill those upper bits.

lb copies the byte’s sign bit into every upper register bit. This is sign extension: it preserves the byte’s signed two’s-complement value. lbu fills every upper bit with zero, preserving its unsigned value. Both read the same one-byte memory location.

The example loads one byte both ways without changing memory between the loads. Predict the unsigned result in t2, then compare its complete hexadecimal pattern with t1. A different register reading alone does not perform an extension; these two load instructions actually write different upper bits.

Predict, then check

What unsigned value does lbu leave in t2 for the supplied first byte?

The memory byte supplies the low eight bits and lbu supplies zero for every upper bit.

    Inspect the register bits

    What the instructions do

    When the byte’s top bit is clear, both extension rules write the same register pattern. A byte with that bit set reveals the difference. Inspect the upper hexadecimal digits as well as the decimal readings; they show the bits that the load supplied.

    The same distinction exists at other transfer widths. lh and lhu load sixteen memory bits with sign or zero extension. lw loads thirty-two bits and sign-extends them, whereas lwu zero-extends them. An RV64 word load therefore does not necessarily clear the upper thirty-two bits.

    Choose from the stored data’s meaning, not from the fact that addresses and destination registers are wide. The unsigned spelling changes extension, not the number of memory bytes read. Use addresses aligned for the chosen width, as the supplied data region is.

    Change it and run again

    Try a first byte whose top bit is clear, then one whose top bit is set. Compare both registers in hexadecimal.

    A hint

    The disagreement is in the bits above the transferred byte, not in the byte read from memory.

    Use it on fresh inputs

    The first four bytes encode a little-endian 32-bit pattern. Load it with lw into t1 and with lwu into t2. Do not modify memory.
