Keep the bits that fit

Observe a sum that exceeds a 64-bit register’s unsigned range.

A 64-bit register has a fixed number of bit positions. add writes the low 64 bits of a sum. If the exact unsigned sum needs another bit, that extra bit is not stored in the destination.

The unsigned range runs from zero to 2 to the power 64 minus one. Moving beyond its top returns the stored pattern to the start of that range. This is fixed-width wrapping; it is not an instruction that chooses to reset a counter.

The example places a value close to the top of the range in t0. Read t0 and t2 as unsigned for this prediction. RISC-V add does not automatically store a separate result saying whether the unsigned or signed range was exceeded. The next lessons build explicit checks when the program needs them.

          Inspect the register bits

          What the instructions do

          The exact mathematical sum and the stored register pattern answer different questions. The exact sum can be too large for one register, while the low bits still have a precise architectural result.

          Changing the displayed signedness does not recover the discarded high bit. It only gives the remaining 64 bits another reading. If you need to know that the sum crossed the unsigned boundary, your code must compute or preserve that information.

          Wrapping can be intentional for a tick counter. It can be a fault for a distance total that must never decrease. Before adding a check, decide what the quantity is supposed to mean. The same add instruction can serve both uses.

          How a counter wraps

          Each tick adds one. This teaching counter keeps only 4 bits; the lesson program uses 64-bit registers. Its readings are unsigned: zero or positive.

          Press +1 to add a tick. Keep pressing until the stored reading returns to zero. Watch Carry out at the wrap. Reset starts at zero.

          Optional: subtract one and inspect the borrow

          The processor’s arithmetic and logic unit (ALU) can subtract when an instruction such as sub requests it. Subtracting one is a decrement. This separate 4-bit counter explores subtraction; it does not reverse time or undo an earlier operation.

          Press −1 once from zero. Inspect Borrow needed and the stored reading. Keep pressing to count down through further wraps. Reset starts this counter at zero.
