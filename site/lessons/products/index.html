Keep the product bits you need

Multiply a pulse count by its scale and inspect the low 64 bits that survive.

The trip computer turns sensor pulses into a distance by multiplying the pulse count by a scale. The answer to a multiplication is its product. Two 64-bit inputs can require 128 bits for their full product, but one register still has room for only 64.

mul t2, t0, t1 multiplies the values in t0 and t1 and writes the low 64 product bits into t2. Any higher bits are discarded. This instruction uses the same low bits for signed and unsigned readings; it does not set an overflow flag.

The first two li instructions load the factors. Predict the hexadecimal pattern in t2 after all three lines run. The destination still holds only 64 bits.

      Inspect the register bits

      What the instructions do

      A destination register cannot retain bits above its width. Reading the result with a different interpretation changes what the retained pattern means; it cannot recover discarded product bits. Small examples can hide that loss because their full product already fits.

      A multiply followed by an add implements a scaled running total. Keep the existing total until the addition reads it. The optional exercise uses t3, another temporary register, to hold the product while t2 still holds its incoming total.

      Unsigned C multiplication has a corresponding wrapping rule for its result type. Signed C multiplication is different: an unrepresentable mathematical result has undefined behaviour. The existence of a hardware low-bit result does not give that signed C expression a defined answer. Undefined behaviour means that C makes no promise about what that program does.

      Change it and run again

      In the example, change the first two instructions to li t0, 0x7fffffff and li t1, 2. Choose Build & Run and note the hexadecimal pattern for t2 in Registers. Change only mul t2, t0, t1 to mulw t2, t0, t1, run again and compare t2.

      A hint

      mulw keeps a 32-bit product and sign-extends that result to 64 bits. It does not provide an unsigned wider product.
