Module 4 · Comparisons and branches

Choose which instructions run

Use a label and a conditional branch to select a warning path.

Loading lesson…

These observations belong to the source captured at the start of this run. Build again to use your edits.

A fuel warning should change only when the remaining fuel is below the reserve. Executing every instruction in sequence would make it difficult to keep the normal and warning outcomes separate. A branch can change which instruction runs next.

A label is a name followed by a colon, such as safe:. It names a place in the code; it is not an instruction. bgeu t0, t1, safe continues at safe when the unsigned value in t0 is greater than or equal to t1. Otherwise, execution continues with the next instruction. A branch that jumps to its target is taken.

The example starts with a clear warning in t2. A taken branch skips the line that would set it. Predict the final warning for the fuel and reserve shown in the first two lines. RISC-V compares the two registers directly in this branch; there is no earlier comparison flag to become stale.

      What the instructions do

      A branch selects a path through the existing instruction sequence. It does not move the target instruction or run a label. In this example, either the warning-setting line runs or it is skipped. Both paths then reach the supplied observation code.

      beq branches on equal register values; bne branches on unequal values. blt and bge use signed ordering, while bltu and bgeu use unsigned ordering. j label is an assembler pseudo-instruction for an unconditional jump. An unconditional jump can prevent one outcome from falling through into another.

      Put more specific rules before broader rules when both could apply. Zero fuel is also below a positive reserve. If an empty tank needs a distinct warning value, test for zero before testing whether fuel is below the reserve. Equality with the reserve belongs to the normal path in this rule.

      Change it and run again

      Try fuel below, equal to and above the reserve. Then swap the two input registers in bgeu.

      A hint

      Trace the condition in its written source order before deciding whether the warning assignment is skipped.

      Use it on fresh inputs

      Unsigned fuel arrives in t0 and reserve in t1. Leave 2 in t2 for an empty tank, 1 for nonzero fuel below reserve, and 0 otherwise. Preserve the inputs.

      Each case starts a fresh xv6 machine. The same submitted code must pass every case.
