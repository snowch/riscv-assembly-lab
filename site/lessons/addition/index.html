Add two register values

A register is a small store inside the processor. RISC-V integer registers hold 64 bits each. The names t0, t1 and t2 select three of these registers. They are temporary registers, used for working values.

An instruction tells the processor to perform an operation. In add t2, t0, t1, the last two operands are inputs. The first operand names the destination, the register that receives the sum. Reading an input does not replace its value.

li loads a number into a register. It is assembler shorthand: the assembler, which translates this text into machine instructions, may expand it into more than one instruction. Read the three lines from top to bottom. Build & Run assembles and executes them; the result cards show the registers after all three lines.

    Inspect the register bits

    What the instructions do

    The addition reads the values already loaded into its two source registers. It writes only its destination. Check both input cards as well as the result card: this distinguishes using a value from changing it.

    The lab supplies the surrounding program that starts execution, captures the registers and exits. View complete program makes that code available. The three editable lines are real assembly inside that program, and the result comes from execution.

    An instruction does not know that a value means distance, a count or a reading. You choose registers for those jobs. Changing a register name changes which stored value the instruction reads or writes.
