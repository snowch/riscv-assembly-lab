Optional guide: Using the workbench

A register is a small store inside the processor. RISC-V integer registers hold 64 bits each. The names t0, t1 and t2 select three of these registers. They are temporary registers, used for working values.

An instruction tells the processor to perform an operation. The parts after its name are its operands. In add t2, t0, t1, the last two operands name the input registers. The first names the destination, the register that receives the sum. Reading an input does not replace its value.

li (load immediate) puts a number into a register. An immediate is a number written directly in the instruction. In li t0, 7, that number is 7. The assembler translates assembly text into machine instructions. li is shorthand that it may expand into more than one machine instruction.

Read the three lines from top to bottom. Build & Run assembles and executes them. The result cards show the registers after all three lines.

    Pinned registers

    Pin a register to keep its readings together. “Changed” compares the current observation with the preceding pause or captured result. Watches do not stop execution.

    Memory watches

    A memory watch reads bytes when the machine pauses. Choose a base address, a signed byte offset and a width. Bytes are read in little-endian order: the first byte holds the lowest eight bits of the value. New watches refresh at the current pause without executing an instruction.

          What the instructions do

          The addition reads the values already loaded into its two source registers. It writes only its destination. Check both input cards as well as the result card: this distinguishes using a value from changing it.

          The lab supplies the surrounding program that starts execution, captures the registers and exits. View complete program makes that code available. The three editable lines are real assembly inside that program, and the result comes from execution.

          An instruction does not know that a value means distance, a count or a reading. You choose registers for those jobs. Changing a register name changes which stored value the instruction reads or writes.

          Change it and run again

          Change li t0, 7 to li t0, 19 and li t1, 5 to li t1, 23 in the editor. Predict the value in t2, then choose Build & Run. In Registers, check t0 and t1 beside t2: did the add change either input?

          Use the first operand to find the register that is written.
