## Implementation and review record

The standalone app uses the same `createWorkbench` controller, markup, editor, debugger, builder, worker and model as the lessons. Curriculum-only activity bindings are conditional and their controls are absent from the standalone DOM. The project shell owns storage and import/export; the shared controller owns execution and observations. Complete assembly source bypasses instrumentation and has no reporting checkpoint. An asynchronous system-call step waits for the actual return to user text or xv6 shell completion, within the existing active-run deadline.

The independent copy pass is recorded in `playground-copy.md`; canonical text is in `content/guides/playground.json`. The independent learner and technical records document their findings and rechecks. Corrections include compact project management, standalone styling that survives fullscreen reparenting, explicit observation moments, consistent full-program help, C project highlight preservation, exclusive keyboard/pointer menus, a fresh Before memory view, preservation of another tab's source, native middle/context-menu handoffs and stepping through an actual exit syscall. No findings remain unresolved in the reviewed scope. Reviewers checked actual CPU runs, imported/exported settings, blocked/quota/corrupt storage, real new tabs and a GitHub-Pages-style subpath.

## Local verification

- The first shared-refactor browser subset passed six checks. The initial standalone subset passed 14 checks, and the final focused playground run passed all 18, including the added native-new-tab and explicit-exit regressions. These were separate commands with no skips.
- The final full browser suite passed all **96 checks**, without skips, in 6.4 minutes. Existing lesson predictions, exercise cases, source recovery, calculator, native/fallback fullscreen and downloads remain covered alongside the new independent workspace.
- The first combined unit/execution run passed 27 checks and failed one new test that incorrectly assumed xv6 set a raw program's initial t0 to zero. The observed value was unspecified. The test was corrected to verify the actual entry and the first executed `li`, rather than changing execution to match the assumption. A focused two-test execution rerun passed; the final combined run passed all **29 checks** with no skips.
- The complete course command passed: 57 native worked examples, 196 native reference cases, 57 rejected incomplete starters, all 58 xv6 worked examples, three xv6 syscall cases and one rejected incomplete syscall starter. No failures. Native syscall cases are intentionally distinguished from their xv6 counterparts.
- All **26 pinned assets** verified. The editor bundle rebuilt with its 15 pinned licensed dependencies without changing the bundle or manifest. Formatting, JavaScript syntax and whitespace checks passed. The static generator now includes the standalone page in CI's generated-output check.

Two development syntax/format commands failed while extracting the shared template/controller (a split optional chain and nested template quoting). Both edits were corrected before their browser checks. An early smoke command targeted a test server that had already stopped and failed with connection refused; the smoke checks then ran against the persistent preview server. These command failures are separate from the passing final checks above. Reviewers' own probe corrections are documented in their records.

The tests use Chromium and actual execution, not physical mobile hardware or a novice study. They do not add or certify reverse execution, physical timing, console input or floating-point process state. GitHub repeats the required checks before publishing; local success does not by itself establish a live deployment.
