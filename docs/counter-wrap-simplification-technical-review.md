## Source and test assessment

The exact mathematical model is unchanged. Each full addition, separate carry and retained pattern agrees. The local note identifies a four-bit teaching model beside real 64-bit RV64 code, and the architecture note states that RISC-V has no carry or signed-overflow flag. Neither the source text nor native register output is updated by the miniature's controls.

Initial state names the starting reading and hides completed arithmetic. At the final bounded tick, Advance disables and Reset receives focus without scrolling. Reload restores the isolated addition-view key; Reset hides the completed addition and restores its starting guidance. Old stored elapsed-view state is left untouched rather than deleted. Mounting safely returns when the figure is absent from elapsed-time.

The addition-only figure no longer carries a second elapsed-time explanation or timeline. Browser tests still assert full sums, operand bits, carry and retained bits, keyboard operation, final focus, native/source independence, saved state, invalid/blocked storage and 320px behaviour. The native/project-copy scenario now runs on the page that actually retains the miniature; it continues to exercise original and edited real code. The pure mathematical and native test obligations remain.
